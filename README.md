# Matleena Painting

Welcome to the Matleena Painting website repository. This project is a stunning, contemporary portfolio website for Matleena Rantanen, a visual artist specializing in vibrant, emotional, and thought-provoking paintings.

## 🎨 Features
- **Contemporary Design:** A dark-mode aesthetic with vermillion accents, designed to feel like an exclusive art gallery.
- **Responsive Layout:** Beautiful on both desktop and mobile devices.
- **Dynamic Interactions:** Smooth scroll, fade-in animations, and interactive galleries to engage visitors.
- **Portfolio Showcase:** Dedicated sections for original artworks, custom commissions, and exhibitions.

## 🚀 Getting Started
To view this project locally:
1. Clone the repository: `git clone https://github.com/Santtujuhana/ByMatleena.git`
2. Open `index.html` in your favorite web browser.
3. No build tools required! This is a clean HTML/CSS/JS project.
